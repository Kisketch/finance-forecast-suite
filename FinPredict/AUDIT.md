# FinPredict 准确率审计（独立页）

> **一句话结论**：FinPredict 的方向准确率与学术共识一致（A 股日频 54% 量级，基准"始终看多"56.5%），**98.7% 不可达**。它的价值不在虚构准确率，而在于**选择性输出**——校准概率接近 0.5 时明确输出"无信号"，只在有把握时给方向。

- 审计日期：2026-10-22
- 标的：上证指数（000001.SS，腾讯行情日 K 640 根 ≈ 2.5 年）、腾讯控股（0700.HK）
- 验证框架：扩展窗口 walk-forward，**无未来函数**（训练集目标在预测点前已实现）
- 关联：姊妹应用 FIN_Terminal 的完整审计见 [../AUDIT.md](../AUDIT.md)

## 1. 模型结构

| 组件 | 说明 |
|------|------|
| 特征 | 42 个 Alpha158 风格因子（动量 / 量价 / 技术 ADX+KDJ / regime 波动率分位 / 季节） |
| 点预测 | Ridge + HistGradientBoosting 回归集成 |
| 方向概率 | Logit + HistGBM + ExtraTrees，**isotonic 校准**（CalibratedClassifierCV）+ 2 年半衰期时间衰减权重 |
| 输出 | 方向 + 中位价 + 95% 区间（滚动残差分位，跨度越大区间越宽） |
| 选择性 | \|p−0.5\| ≥ 0.05 才给方向，否则"无信号"（-1） |

## 2. A 股日频（000001.SS, horizon=1）实测

| 指标 | 值 | 判定 |
|------|---:|------|
| 回测折数 | 200 | 扩展窗口，测试点间隔 = horizon |
| 方向准确率（回归点预测） | 54% | 接近随机 |
| 基准"始终看多" | 56.5% | 模型未跑赢最简单基准 |
| MAE | 0.72%（对数收益） | 随机游走 0.70% |
| Skill | −2.7% | 负值，诚实保留 |
| 校准概率方向准确率 | 见「回测检验」页 | 全程口径 |
| 有信号日准确率 | 见「回测检验」页 | 选择性口径（51% 覆盖时可达 57.1%，见 FIN_Terminal 同法验证） |

**解读**：日频方向预测本身极难（学术共识 54–58% 上限），FinPredict 不掩盖这一点——它的定位是**情景参考 + 有信号才下注**。

## 3. 选择性输出的意义

```
p_up = 0.49  →  无信号（不下注）      ← 当前时点实测
p_up = 0.78  →  看涨（可下注）
```

概率经 isotonic 校准后，`predict_proba` 反映**经验频率**而非模型自信度；选择性阈值把"几乎不可预测"的多数日子显式排除，这是比硬给方向更诚实的产品设计。

## 4. 多周期区间宽度（跨度越大，精度越低）

| 周期 | horizon | 区间宽度（95%） | 说明 |
|------|--------:|---------------:|------|
| 1 小时 | 1 根 | 窄 | 短期噪声大，方向近乎随机 |
| 3 小时 | 3 根 | 中 | 仍受日内噪声主导 |
| 1 天 | 1 根 | 中 | 最受关注的日频 |
| 1 个月 | 21 根 | 最宽 | 月度不确定性最大，区间显著变宽 |

区间为**滚动残差分位映射**（非固定倍数），因此自动体现"跨度越大越不确定"。

## 5. 已知局限（诚实清单）

1. **免费数据源延迟**：腾讯/yfinance 约 15 分钟延迟；yfinance 美股偶发限流（3 次重试 + 友好降级）
2. **腾讯美股历史短**：美股建议用 yfinance 源；A 股/港股优先
3. **日频方向准确率天花板**：~54-58%，与始终看多基准相当
4. **非线性依赖未纳入**：本应用仅有价量，无盈利/一致预期/资金流/期权 IV
5. **委员会分析依赖 LLM**：需用户自行配置端点；LLM 输出可能出错，**不应作为唯一决策依据**
6. **98.7% 方向不可达**：任何声称可达的同类回测，先查未来函数 / 目标偷换 / 全样本调参 / 高置信小样本 / 生存者偏差

## 7. 结论

FinPredict 达到的是**诚实可用**的水平：数据实时、预判可解释（方向+区间+概率）、回测可复核、无信号不下注。它没有、也不应声称 98.7% 的方向准确率。
