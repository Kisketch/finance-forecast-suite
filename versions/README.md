# Version Snapshots

This folder contains four curated feature-stage snapshots:

1. `01_core_terminal/` — original terminal + first 27 backtests.
2. `02_accuracy_audit/` — accuracy audit, interval calibration, rare-event reweighting, open-source review.
3. `03_news_llm/` — official news, LLM adapter, constrained optimizer, model access page.
4. `04_merged_suite/` — **v1.3**: FinPredict app merged in (42-factor calibrated ensemble + multi-agent AI committee), app icon, five-language READMEs, MIT license, accuracy-evidence pages, Git development workflow, release binaries.

They are curated snapshots, not complete historical source trees. The authoritative runnable version is always `../project/` (FIN_Terminal) and `../FinPredict/` (FinPredict).

See `../VERSION_NOTES.md` for the version map, `../CHANGELOG.md` for the full change log, `../AUDIT.md` for the accuracy evidence, and `../REASONING_AND_DECISIONS.md` for the decision chain.
