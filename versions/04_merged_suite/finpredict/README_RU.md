# FinPredict · Настольное приложение для прогнозирования финансовых тенденций в реальном времени

**Язык / Language / Langue / Язык / Idioma**: [中文](README.md) · [English](README_EN.md) · [Français](README_FR.md) · [Русский](README_RU.md) · [Español](README_ES.md)

![Иконка FinPredict](src/finpredict/web/icon.png)

**Запускается двойным щелчком** настольное приложение для Windows: получает официальные рыночные данные в реальном времени через сеть, прогнозирует тенденции на нескольких временных горизонтах, проверяет результаты историческими бэктестами и включает встроенный многоагентный ИИ-анализ. Не требует установки Python или каких-либо зависимостей.

![Интерфейс котировок в реальном времени](docs/screenshot_quote.png)

## ✨ Ключевые функции

| Страница | Возможности |
|----------|-------------|
| 📈 Котировки в реальном времени | Загрузка свечей онлайн по 4 горизонтам: 1 час / 3 часа / 1 день / 1 месяц; свечи + MA + Полосы Боллинджера + RSI + MACD + объём |
| 🔮 Прогноз тенденций | Направление на нескольких горизонтах + медианная цена + 95% доверительный интервал (шире для более длинных горизонтов); 42 фактора + ансамбль с калибровкой вероятностей |
| 🧪 Бэктестинг | Скользящая валидация walk-forward: точность направления / MAE / Skill / доходность стратегии против покупки и удержания |
| 🤖 ИИ-помощник | Эндпоинты, совместимые с OpenAI; 5 шаблонов промптов без написания; **многоагентный комитет** (роли: технический / фундаментальный / риск-аналитик / трейдер / управляющий, вдохновлено TradingAgents) |

## 🚀 Быстрый старт

**Вариант 1 (рекомендуется)**: распакуйте и дважды щёлкните `FinPredict.exe` — нулевые зависимости, данные предварительно загружаются при запуске (мгновенно, без зависаний).

**Вариант 2 (из исходников)**:
```powershell
py -m pip install -r requirements.txt
py -m finpredict.app
```

**Примеры символов**: `000001.SS` (Сводный индекс SSE) · `0700.HK` (Tencent) · `AAPL` (Apple) · `^GSPC` (S&P 500) · `CL=F` (нефть WTI)

## 📡 Источники данных (бесплатно, без API-ключа)

| Рынок | Основной источник | Резервный |
|-------|-------------------|-----------|

| Акции США, индексы США, сырьевые товары, валюты | yfinance (3 повторные попытки) | плавная деградация при ограничениях Yahoo |

## 🤖 Подключение ИИ (без написания промптов)

Введите любой совместимый с OpenAI эндпоинт на странице «ИИ-помощник»:

| Эндпоинт | Базовый URL | Модель |
|----------|-------------|--------|
| Ollama (локально) | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

**Шаблоны промптов** (автоматически заполняются данными в реальном времени): Анализ тенденций · Объяснение аномалий · Факторная атрибуция · Советы по действиям · Обзор бэктеста

**Режим комитета**: одним щелчком запускается многоагентный анализ с 5 ролями — технический аналитик, фундаментальный аналитик, риск-аналитик и трейдер оценивают независимо; управляющий портфелем взвешивает все мнения и выносит окончательное заключение (архитектура вдохновлена TradingAgents / ai-hedge-fund, реализована независимо).

## 🧮 Метод прогнозирования

- **Признаки**: 42 фактора в стиле Alpha158 (моментум / цена-объём / технические / режим / сезонность, вдохновлено Microsoft qlib)
- **Модели**: ансамбль регрессии Ridge + HistGradientBoosting; вероятности направления откалиброваны изотонической регрессией (Logit+HistGBM+ExtraTrees) с весами временного затухания
- **Валидация**: walk-forward с расширяющимся окном, без подглядывания в будущее; интервалы из скользящих квантилей остатков
- **Вдохновлено**: qlib (факторная инженерия) · TradingAgents (многоагентный комитет) · ai-hedge-fund (многостилевые взгляды) · Lopez de Prado AFML (калибровка + селективный вывод) — только архитектурные идеи, код не скопирован

## ⚠️ Честные границы

**Точность направления 98,7% недостижима вне выборки** (академический консенсус; потолок ежедневного прогнозирования направления составляет примерно 54-58%). Прогнозы являются сценарными ориентирами — не инвестиционными рекомендациями, исполнение сделок не выполняется.
